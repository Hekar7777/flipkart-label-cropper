The format these documents use

A Flipkart “combined” shipping document packs two logically separate documents onto one A4 page, stacked vertically:

SectionApproximate positionTypical contents
Shipping label Top ~55–60% of the page Courier header, AWB barcode, QR code, ship-to address block, SKU table, a footer barcode, and a “Not for resale” line.
Tax invoice From the “Tax Invoice” heading to the bottom GSTIN and invoice numbers, billing and shipping addresses, product and HSN table, totals, and the seller signature block.

Because the two sections serve different purposes — one goes on the parcel, the other goes to accounting — they usually need to be separated before printing or archiving. Doing that by hand for a day's worth of orders is slow and error-prone, which is what this tool automates.

The download that carries this layout is named invoice_labels_<number>.pdf, one order to a page. If that filename is what sent you looking for an answer, the tool page explains what the invoice_labels PDF contains in more detail.

How the split and crop work

For every page of every file you drop in, the tool runs three steps.

  1. Find the split line. The page text is read and searched for the heading “Tax Invoice”. That heading's vertical position marks the boundary between the two sections. If a page has no such heading — an unusual variant, for instance — the tool falls back to a proportional split and says so in its activity log rather than failing.
  2. Measure the printed content. The page is rendered at high resolution and scanned row by row and column by column to find where ink actually is. Two levels of detection are used: strong ink defines the content, and lighter shading is only included where it touches that content. A crop edge is only ever taken from ink that has real vertical structure — a border, a column of text, a barcode, a QR block. Page furniture such as dashed “cut here” lines, colour bands and page frames supplies only a hairline and is therefore left out, so no blank paper comes along with the label.
  3. Produce the cropped PDF. The original page's content is copied into a new page sized exactly to the measured box plus your margin. Nothing is rasterised or re-rendered, so text stays selectable and barcodes stay scannable at any print resolution.

When to use manual crop

Automatic detection handles the standard combined layout well. Switch to manual crop when you are dealing with something non-standard, such as a different paper size, an unusual header, or a document that carries more than two sections.

Manual mode opens a live preview of the page with two draggable regions. They are stored as percentages, so they apply consistently to every page and to every file in the batch. You can turn auto-tightening off if you want your region used exactly as drawn.

Printing tips

  • Print at 100% (Actual size), not “fit to page”. A uniform scale keeps barcode module widths proportional, which is what a scanner reads. The cropped page is already the size of the printed label, so there is no surrounding A4 to trim first.
  • Know your media size. 4×6 in is 101.6 × 152.4 mm — sold as “100 × 150 mm” — 4×5 in is 101.6 × 127 mm, and 3×5 in is 76.2 × 127 mm. The label size table lists each one with what it is used for.
  • Printing on A4? Pack four labels to a sheet. Switch on 4 labels per A4 sheet in the crop controls above the file list, and four cropped labels are placed on one 210 × 297 mm page, each scaled to fit its quarter — the same approach as laying labels out by hand, without the cutting and pasting. Invoice pages follow the sheets at their own size.
  • Keep at least a 5 mm quiet zone around barcodes. A 4–6 pt margin (roughly 1.5–2 mm) is applied by default; increase the margin in Advanced settings if your printer struggles.
  • Print one label first and scan it before running the rest of the batch. If the scan fails, the usual causes are a “fit to page” setting that rescaled the page, or a print scale set below 100%.
  • Archive the invoice files alongside your books — they retain the original invoice number, date and tax breakdown.
  • Because output is vector, thermal printers produce crisp barcodes without the fuzzy edges you get from a screenshot or a scanned copy.
  • A thermal printer pays for itself in roll stock and saved A4 sheets once you are dispatching daily; below that, printing the label half on A4 at actual size is perfectly serviceable, and this tool gives you the same cropped page either way.

Privacy and security

This tool has no backend. Files are opened with the browser's file API and every step — rendering, measuring, cropping, combining — happens in your tab. Your shipping documents are never uploaded, so customer names, addresses and order numbers stay on your machine. You can even save the page and use it offline. Frequently asked questions

Are my files uploaded anywhere?

No. There is no upload step in the code and no server that receives documents. Everything runs in your browser.

What are the output files called?

By default the batch comes back as one combined PDF — every label and its invoice in order, pages at their cropped sizes. Choose Individual PDFs and you get per-page files instead: for order.pdf that is order_label.pdf and order_invoice.pdf, and if a file has several pages each page is numbered: order_p1_label.pdf, order_p1_invoice.pdf, and so on. Labels-only or invoices-only mode keeps the same one-PDF output but with only that section on every page.

Can I get just the labels for 4x6 thermal printing?

Yes — set the Output selector to Labels (or Files for one PDF per page). The label pages keep their cropped sizes, so a thermal printer scales the nearest size onto the roll and the invoice never reaches the printer.

How many files can I process at once?

Batches of 20 or more are fine. Files are processed a few at a time so the tab stays responsive, and you can stop a batch partway through. If one file is corrupted or password-protected, it is flagged and skipped — the rest of the batch continues.

Will the barcodes and QR codes still scan?

Yes. The crop copies the original vector content rather than screenshotting it, so barcode bars, QR modules and text keep their exact geometry. Just make sure the label preview looks complete before you print.

Do the output PDFs keep the same proportions?

Yes. A crop only changes how much page surrounds the content, never the content's scale — so the aspect ratio of the printed label is preserved exactly.

Does it work with other couriers?

The automatic split looks for a “Tax Invoice” heading and printed-content boundaries, so it often works on any combined label-plus-invoice sheet. For formats that differ significantly, manual crop mode is the reliable route.

Is it really free?

Yes — no account, no subscription, no file limits, no watermark. The site is funded by the advertising shown on the page.
